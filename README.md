## Lancer le projet
Deux possibilités:1-cliquer sur Code puis "Download Zip"
2-cloner le projet en ouvrant un terminal puis cloner l'adresse: https://github.com/musta93cr/museum-valbrune.git
Ouvrir le dossier museum-valbrune dans Visual Studio Code,
installer l'extension Live Server(pour voir les modifications en direct s'il y en a);
faire un clic droit sur index.html et cliquer sur "Open with live server"
